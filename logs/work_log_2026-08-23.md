## 2. Technical Challenges & Fixes

- **상대가 예고 없이 바뀐다**: base UUID가 `-0000-1000-` → `-1234-1234-`로 변경돼 있었고
  GitHub HEAD와 로컬 빌드가 달랐다. 16비트 short UUID 매칭으로 양쪽을 수용하고, 이후
  사용자가 "의도된 변경"임을 확인해 계약서에 확정했다.
- **광고 배치가 빌드마다 다르다**: MINIMAL 모드의 전화번호 4자리 위치가 세그먼트 4와 5로
  갈린다. 두 배치를 모두 지원하도록 하고 "단순화 금지"를 constitution에 명시.
- **fallback이 위험했다**: 블랙리스트 5개로는 폰이 노출하는 수십 개의 쓰기 가능 시스템 특성을
  못 막는다. SIG base(`…-0000-1000-8000-00805f9b34fb`) 전체를 fallback에서 배제하는 규칙으로 교체.
- **내가 만든 회귀 2건**: 링크 사망 후 `None` 참조(`c1f079b`), 그리고 예외 핸들러가
  `self.target_write_char`를 참조해 에러 경로 자체가 터지던 문제(`66c6a10`에서 로컬 바인딩으로 수정).
- **에이전트를 파일 수정과 동시에 돌리면 오탐**: `ble-peer-analyst`가 커밋 직전 파일을 읽어
  이미 고친 내용을 "미수정"으로 보고했다. 순차 실행이 맞다.
